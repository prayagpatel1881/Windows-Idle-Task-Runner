# Windows Pre-Emptive Optimizer

A simple, one-click optimization script for Windows 10 and 11 that prepares your PC for heavy lifting. 

Rather than just clearing RAM, this tool forces Windows to immediately execute all its pending background maintenance chores (like search indexing, system diagnostics, and disk optimization). 

**Why use this?**
Windows often waits until your PC is "idle" to run background chores. If you start gaming or rendering a video, Windows might mistakenly trigger these tasks, causing sudden lag, frame drops, or memory spikes. This script forces those tasks to finish *before* you start your work.

**Benefits:**
* **Zero Interruptions:** Prevents background maintenance from unexpectedly stealing CPU and disk resources.
* **Consistent Performance:** Keeps your frame rates and processing times stable during heavy workloads.
* **Battery Management:** Forces background battery drain to happen on your schedule, not randomly.

**How to Install and Use:**
1. Download the `TaskRunner.bat` file.
2. Right-click the file and select **Create shortcut**.
3. Drag the new shortcut to your Taskbar for one-click access.
4. Click the icon a few minutes before launching a heavy application.

> **Note:** When you click this tool, your CPU and disk usage will temporarily spike as Windows crunches through its chores. Give it a minute or two to settle down, and your PC will be fully primed for heavy tasking!
